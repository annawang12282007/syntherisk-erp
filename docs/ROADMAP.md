# 產品發展方向

目前產品定位：以台灣中小型組織為主，每客戶獨立部署，由導入、訓練及持續維護服務收費。以下是後續工作，不代表初版已完成。

## 首批客戶導入前

- 依客戶實際出勤制度進行平行薪資試算，由其薪資負責人簽認差異與排除項目。
- 完成備份還原演練、權限設定、HTTPS／郵件設定、資料匯入與操作訓練。
- 對支援範圍、回應時限、更新方式及停止代管後的資料交接訂立書面服務約定。
- 進行獨立安全檢查，建立漏洞處理及更新通知流程。

## 台灣人事完整度

- 國定假日、例假、特休與各類請假；假日行事曆採版本化且需管理員確認。
- 到離職比例、月中調薪、補發與更正薪資，保留原核准明細。
- 勞保／健保／勞退及扣繳規則的版本管理、試算與覆核。
- 勞工可讀的薪資單、差異檢查及經雙人確認的匯出流程。
- 班表模板、換班申請、連續工作／休息間隔檢查與主管審核。

## 維護服務產品化

- 客戶安裝版本與服務到期紀錄放在維護方的管理系統，不作為客戶系統的功能鎖。
- 版本發布說明、相容性與 migration 檢查、自助備份還原及升級驗收指南。
- 依導入規模與服務範圍報價；價格與服務時限由實際營運成本決定。
