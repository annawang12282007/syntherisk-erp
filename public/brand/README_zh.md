# Syntherisk / D Precision 標誌

以選定原稿的高解析版本重建雙色 S 與字標輪廓，移除原圖光影與材質。字標為向量輪廓，並非以近似字體重新打字。描述語以 Liberation Sans 重建並轉外框。所有 SVG 均不含點陣圖與外部字體依賴。

- logo-primary：橫式主標誌，不含描述語。
- logo-full-lockup：完整標誌＋Route reliability intelligence。
- logo-white／logo-mono／logo-black：單色版本。
- logo-reverse：深色背景專用，保留青綠上半部、其餘反白。
- logo-stacked：直式組合。
- symbol：独立 S，1024 px 透明 PNG。
- favicon.svg／favicon.ico／favicon-*.png：網站小圖示；apple-touch-icon.png：180 px。

主標誌 PNG 為 2400 px 寬、透明底。圖案勿拉伸或改變字距。主標誌周圍保留至少字標大寫 S 高度的 1/2 空間；含描述語版本建議最小寬度 320 px／55 mm，低於此寬度改用無描述語版本。

使用字標向量原檔；Liberation Sans 用於其他文案，不作為重打字標的替代。正式印刷前使用印廠色彩設定打樣，商標可註冊性尚未查驗。
